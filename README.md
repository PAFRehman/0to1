# PenguMint

A student blockchain studio on **Base Sepolia**. Create a wallet, sign a creation, review gas and publish it to a live classroom wall. **Pip is the single penguin guide.** The original moving 3D coastline, articulated guide, celebration jet and music remain. The couple, flowers and apology workflow have been removed.

## Useful things students can do

- Mint notes, compact artwork and drawn creative signatures as ERC-721 records.
- Publish larger images, GIFs, video, audio or PDFs through IPFS; record their URI, checksum and creator proof onchain.
- Prove a private assignment or research file using its SHA-256 checksum. The file never leaves the student's device.
- Link a revised project to an earlier creation by the same wallet. Both versions remain verifiable.
- Have another wallet witness a creation once. This is a peer acknowledgement, not an academic grade.
- Build an onchain learning passport with counts for media, notes, signatures, private file proofs and peer witnesses.
- Share a public creation link or a classroom contract link. Confirmed changes appear automatically.

## Start locally

Use **Node 24** and npm.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000. No private key belongs in an environment variable. A wallet needs free **Base Sepolia test ETH** to deploy a wall or publish a creation. The package does not contain an already-funded wallet or a deployed testnet address. Use **Set up your classroom wall** to estimate gas and deploy the included contract from your wallet, or enter an existing PenguMint contract address.

## Deploy on Vercel

Import the source into a GitHub repository, then import that repository in Vercel. The included `vercel.json` sets the Next.js framework, `npm ci` and `npm run build`. Node is pinned to 24.x. No database migration is required.

1. Deploy the website with default settings.
2. Create/connect a wallet, get Base Sepolia test ETH, and deploy a classroom wall through the setup dialog.
3. Copy the deployed contract address into `NEXT_PUBLIC_MINT_CONTRACT` in Vercel and redeploy. The public default wall is now shared by everyone.
4. Optionally add `PINATA_JWT` and a random `UPLOAD_AUTH_SECRET` for uploads; add `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` for mobile-wallet QR connections.
5. Attach `0to1.world` in Vercel Domains and follow Vercel's DNS instructions. Add that domain to the Reown allowlist if QR connections are enabled.

See [SETUP.md](SETUP.md) for full configuration and the GitHub commands.

## What is genuinely onchain

The contract stores title, note, media URI, SHA-256 file checksum, content commitment, creator's signed approval, original creator, timestamp, parent version and witness count. Each record is an ERC-721 token. Metadata is generated by `tokenURI()` from contract state. Compact raster images and drawn signatures use data URIs directly in contract storage. Larger media is stored separately on IPFS.

The UI signs an EIP-191 creator message bound to chain, contract, creator, content, title and kind. The contract verifies EOA and deployed ERC-1271 wallet signatures. Content hashing uses ABI encoding to keep field boundaries unambiguous. Duplicate content per creator and links to another creator's work are rejected. Published records cannot be edited or deleted; drafts can.

The gallery checks confirmed `activityNonce` every four seconds while visible; it reads new records and witness changes from the contract. It does not fabricate pending mints, sample records or passport scores. Public reading and verification do not require a wallet. No Supabase/Firebase account is needed.

## Wallet choices

- **In-site wallet:** cryptographically random key, PBKDF2 SHA-256 with 310,000 rounds, AES-GCM encryption, encrypted JSON backup/import, explicit locking and idle locking. The key stays in browser memory while unlocked and never goes to the server.
- **Browser wallet:** EIP-6963 discovery plus legacy EIP-1193 injection, network switching and account-change handling.
- **QR wallet:** lazily loaded WalletConnect provider when a Reown project ID is configured.

The wallet is an educational testnet wallet. Download its encrypted backup and retain its password before clearing browser data. The site cannot reset a lost wallet password. Public creative marks should not be banking or official signatures.

```bash
npm run contracts:compile
npm run contracts:test
npm test
npm run typecheck
npm run build
```

Anvil is installed as a development dependency. Contract tests run a local EVM with chain ID 84532; no real testnet funds or secrets are used. See [QUALITY-CHECKS.md](QUALITY-CHECKS.md) for exactly what was verified.
